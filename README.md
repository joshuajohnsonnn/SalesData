# SalesData 

SalesData is a Python-based data analysis project that uses Pandas to analyse sales performance over a given time period. It demonstrates basic data loading, tabular analysis, and statistical summaries using a simple and accessible Python workflow.

## About

SalesData is a Python-powered data analysis project designed to demonstrate how sales data can be loaded, displayed, and analysed using Pandas.

The project provides a straightforward starting point for working with structured sales data and generating useful descriptive statistics.

## Features

- **Data Loading** – Loads sales data from a dictionary or CSV file.
- **Tabular Data Display** – Presents the sales dataset in a readable table.
- **Statistical Analysis** – Generates descriptive statistics using `pandas.DataFrame.describe()`.
- **Simple Project Structure** – Demonstrates how a small Python data-analysis project can be organised for GitHub.

## Getting Started

### Prerequisites

- Python 3.7 or higher
- A command-line environment (e.g., Terminal, PowerShell)
- Pandas and the project's required dependencies
- (Optional) A virtual environment such as `venv` or `conda`

### Installation

Clone the repository:

    git clone https://github.com/joshuajohnsonnn/SalesData.git
    cd SalesData

Install the required dependencies:

    pip install -r requirements.txt

## Usage

Run the analysis script:

    python src/analyze_sales.py

The program loads the sales data and produces:

- The sales dataset in tabular form
- A statistical summary containing values such as the mean, standard deviation, minimum, and maximum
